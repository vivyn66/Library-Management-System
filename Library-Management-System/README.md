# Library Management System

A RESTful Library Management System developed using Java and Spring Boot for managing books through CRUD and bulk operations.

## 🚀 Features

- Add a new book
- Get a book by ID
- Get all books
- Update a book
- Delete a book
- Save multiple books
- REST API architecture
- Swagger/OpenAPI API documentation
- MySQL database integration
- Docker containerization
- Cloud deployment

## 🛠️ Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Docker
- Swagger / OpenAPI
- Render
- Aiven MySQL
